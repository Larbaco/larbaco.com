# Thiago Cabral — Portfolio

Personal portfolio website. Built with React + Vite, deployed on Firebase Hosting.

Live at [larbaco.com](https://larbaco.com)

---

## Features

- **Multilingual** — English/Portuguese toggle
- **Dynamic Resume** — JSON-powered CV with print-optimized layout
- **Project Gallery** — Card-based showcase with links
- **Responsive** — Mobile-first design

## Tech Stack

- React 18 + React Router 6
- Vite
- Bootstrap 5.3
- Firebase Hosting

## Local Development

```bash
npm install
npm start
```

## Deploy

```bash
npm run build
firebase deploy
```
